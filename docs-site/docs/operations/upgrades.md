---
title: Upgrades
---

Before upgrading, record the integration version, provider modes, and any custom model/profile settings. Back up Home Assistant configuration and review release notes.

Install the new HACS version or replace the manual component directory, then restart Home Assistant. If a migration is needed, the integration handles config-entry migration during setup. Validate entities, model profile references, MCP catalogs, and optional capabilities after the restart.

The current release documented here is **0.6.0**. See the [release notes](../release-notes) and [GitHub releases](https://github.com/bradsjm/hacs-pydantic-ai-agent/releases).
