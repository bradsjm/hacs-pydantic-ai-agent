---
title: Install with HACS
---

1. Open HACS in Home Assistant.
2. Open **Integrations → Custom repositories**.
3. Add `https://github.com/bradsjm/hacs-pydantic-ai-agent` as an Integration.
4. Install **Pydantic AI Agent**.
5. Restart Home Assistant.

The integration is intentionally distributed as a custom repository until it is available through the normal HACS catalog.
